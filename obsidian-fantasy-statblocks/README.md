# Import to Obsidian

1. Put the [Style.css](./Style.css) into `.obsidian/snippets` in your Obsidian Folder.
2. Import [Layout.json](./Layout.json) in the [Fantasy Statblocks Plugin](https://plugins.javalent.com/statblocks/settings#Import+from+json) settings.
3. Then you are ready to import the `obsidian-frontmatter` by just placing them inside your Vault (you might need to adjust [the corresponding plugin settings](https://plugins.javalent.com/statblocks/settings#Parse+frontmatter+for+creatures).
4. Optional: remove and disable the DnD creatures.
